# 用户反馈证据归档说明

本目录用于存放真实用户试用证据。请勿放入伪造材料；正式提交前至少补齐 3 类角色的原始证据。

## 建议文件命名

- `U1-导师-访谈摘要.md`
- `U1-导师-试用截图-01.png`
- `U2-轮转生-聊天记录截图.png`
- `U3-管理员-后台数据截图.png`

## 每位用户至少包含

- 姓名或代号、角色、联系方式。
- 试用日期和试用方式。
- 操作过程截图。
- 原始反馈记录：访谈摘要、聊天截图、问卷截图或录音摘要。
- 反馈处理结论：已采纳、后续迭代或暂不处理。

## 隐私处理

如包含手机号、微信号、邮箱或实验室服务器地址，提交公开仓库前请先打码。
